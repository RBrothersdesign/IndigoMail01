CASA ÍNDIGO — EMAIL LISTO PARA PUBLICAR

1. PUBLICAR
Descomprime el ZIP. Sube el CONTENIDO de esta carpeta a un repositorio de GitHub: index.html, email.html, assets y .nojekyll. No subas únicamente el ZIP.
En el repositorio: Settings > Pages > Build and deployment > Deploy from a branch. Elige main y /(root), y guarda.
Abre la dirección HTTPS que GitHub Pages te indique cuando termine de publicar. También sirve cualquier hosting estático HTTPS que conserve esta estructura.
Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

2. LLEVAR A GMAIL
En la página publicada, pulsa “Copiar correo para Gmail”. En Gmail de escritorio, abre Redactar y pega normalmente con Ctrl+V en el cuerpo del mensaje. El modo texto sin formato debe estar desactivado. Añade asunto y destinatario.
Si el navegador bloquea el portapapeles, abre “Ver solo el correo” desde la página publicada, selecciona todo con Ctrl+A, copia con Ctrl+C y pega en Gmail con Ctrl+V.
No pegues el código HTML ni adjuntes el archivo HTML: eso no inserta el diseño.
Envía primero una prueba a tu dirección. Comprueba imágenes y los tres enlaces en computador y móvil. El cliente puede modificar el contenido pegado.

3. PARA UNA PLATAFORMA DE EMAIL
En la página publicada pulsa “Descargar HTML con URLs públicas”. Ese archivo incluye las URLs absolutas de las imágenes; puedes importarlo en una plataforma que admita HTML. email.html usa rutas relativas para la vista previa y el alojamiento.
No se ha publicado nada ni se ha enviado ningún correo desde esta tarea. No hace falta escribir manualmente la URL del hosting: la página de preparación la incorpora automáticamente al copiar o descargar.

DISEÑO Y COMPATIBILIDAD
Referencia: EMAIL.pdf, una página de 1024 × 2157,37 puntos.
El arte se exportó del PDF maestro a PNG de doble resolución y se dividió en piezas sin cambiar sus píxeles. Las imágenes adjuntas ayudaron a comprobar las divisiones y leer el QR. Se empleó el PDF para preservar el color y la tipografía de la referencia maestra.
Correo de ancho máximo 640 px que se reduce proporcionalmente en móvil. La composición no se reorganiza: los textos pequeños también se reducen. Tablas de presentación, estilos inline e imágenes PNG; sin JavaScript, formularios ni posiciones absolutas dentro del correo.
El texto visible forma parte de las imágenes para conservar las fuentes y la composición. Se añadieron textos alternativos. Si el destinatario bloquea las imágenes, no verá el diseño completo hasta habilitarlas.
La página index.html sí usa JavaScript para copiar/descargar; ese código y sus controles nunca forman parte del email copiado.
Mantén las imágenes públicas en la misma dirección después del envío. Los enlaces telefónicos requieren una aplicación que gestione llamadas.
La comprobación visual local no equivale a una prueba de entrega en todos los clientes de correo. No se ha probado un envío real desde tu cuenta de Gmail.
